我的第一篇博客：从零搭建个人博客

为什么要写博客？

作为一个大二程序员，我一直觉得技术博客是最好的学习记录方式。既能沉淀知识，又能作为自己的技术名片。

今天花了几个小时，终于把这个博客从零搭起来了。记录一下整个过程，既是对自己的总结，也希望能帮到其他想搭博客的同学。

我用到了哪些工具？

工具 作用
Hexo 静态博客框架，用 Markdown 写文章，一键生成网页
GitHub Pages 免费托管博客，域名就是 用户名.github.io
Git 版本控制，用来把代码推送到 GitHub
